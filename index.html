HOW TO INSTALL

Install in 3 Simple Steps

Because Zen Mate downloads media directly, it is provided via direct Android APK install.

1

Download APK

Tap the download button to fetch the latest APK. If Chrome warns "File might be harmful", tap Download anyway.

2

Allow Unknown Sources

If prompted by Android security, open Settings and turn on Allow from this source for your browser or file manager.

3

Install & Play Protect

Tap Install. If Google Play Protect displays a prompt, tap More details and select Install anyway.

Why does Android show a security or Play Protect warning?

Because Zen Mate allows direct media downloading, it is distributed directly outside the Google Play Store. Android and Google Play Protect automatically show generic warnings (such as "File might be harmful" or "Unrecognized app") for all third-party APK files. This is completely standard behavior on Android. Zen Mate is 100% clean, contains no spyware, and is safe for your device.
