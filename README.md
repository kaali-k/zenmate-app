## Overview

Zen Mate is an Android media utility and ambient soundscape player engineered with Flutter, yt-dlp, and native Android audio frameworks. Designed with a cyber-neon dark aesthetic, Zen Mate delivers high-speed audio and video extraction directly to device storage without subscriptions or cloud dependencies.

### Core Capabilities

- **High-Fidelity Audio Extraction**: Download YouTube audio in 320kbps MP3 or M4A formats.
- **Full Video Capture**: Download YouTube video streams up to 1080p and 4K with resilient background threading.
- **Native ID3 Tagging & Album Art**: Automatically embeds metadata tags and high-resolution album covers into downloaded audio files.
- **Built-in Ambient Sound Engine**: Curated offline ambient soundscapes (Night Rain, Neon Cyberpunk, Forest, Cafe) with configurable sleep timer auto-fadeout.
- **Background Playback**: Persistent notification drawer controls and lockscreen synchronization for audio playback.
- **Privacy-First Architecture**: Zero telemetry on download history; files remain entirely on local Android storage.
- **Samsung Native Haptic Engine**: Native 28ms micro-click tactile feedback tailored for Samsung Galaxy and modern Android vibrator hardware.

## Download & Installation

The latest official build can be downloaded from the GitHub Releases portal or the web landing page:

- **Direct APK Download**: [zen-mate-v1.0.0.apk](https://github.com/kaali-k/zenmate-app/releases/latest/download/zen-mate-v1.0.0.apk)
- **Web Landing Page**: [https://kaali-k.github.io/zenmate-app/](https://kaali-k.github.io/zenmate-app/)

### Installation Instructions

1. Download the `zen-mate-v1.0.0.apk` file on your Android device.
2. If prompted by Android security, enable **Allow from this source** in your browser or file manager settings.
3. Open the APK file and select **Install**.
4. Grant storage permissions upon first launch to enable local media saving.

## Architecture & Technology Stack

| Layer | Technology |
| :--- | :--- |
| **Framework** | Flutter (Dart 3.x) |
| **Media Stream Processor** | yt-dlp & YouTubeExplode |
| **Audio Playback Engine** | Just Audio & Audio Service (Foreground Notification Service) |
| **Crash Analytics** | Firebase Crashlytics |
| **Native Bridge** | Android Kotlin & Vibrator API |
| **Update Distribution** | Client-side In-App Update Engine via GitHub Releases |
